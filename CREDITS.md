# Crédits

## Graphismes

- **Zelda-like tilesets and sprites**, par ArMM1998 : licence CC0 (domaine public).
  Source : https://opengameart.org/content/zelda-like-tilesets-and-sprites
  Fichiers utilisés : `src/assets/overworld.png`, `src/assets/objects.png`, `src/assets/npc.png`.

- **Carte de l'Égypte et temple** : images générées avec Gemini pour ce projet, d'après les prompts de `docs/style-images.md`.
  Fichiers utilisés : `src/assets/parcours/monde-egypte.jpg`, `src/assets/parcours/temple.jpg`.

- **Salle du temple** : image générée avec Gemini pour ce projet, d'après les prompts de `docs/style-images.md`.
  Fichier utilisé : `src/assets/salles/temple-egypte.jpg`.

- **Torche (stèle)** : image générée avec Gemini pour ce projet, d'après les prompts de `docs/style-images.md`, puis détourée et réduite.
  Fichier utilisé : `src/assets/objets/torche-egypte.png`.

- **Carte des mondes** : image générée avec Gemini pour ce projet, d'après les prompts de `docs/style-images.md`.
  Fichier utilisé : `src/assets/parcours/monde-entier.jpg`.

- **Personnages (explorateur, pirate)** : planches générées avec Gemini pour ce projet, d'après le style de `docs/style-images.md`, puis découpées, détourées et réduites par `outils/decouper-personnage.py`.
  Planches d'origine : `docs/personnages/`. Fichiers utilisés : `src/assets/personnages/explorateur.png`, `src/assets/personnages/pirate.png`.

- **Pictogrammes ARASAAC**, par Sergio Palao. Origine : ARASAAC (https://arasaac.org). Propriété : Gouvernement d'Aragon (Espagne). Licence : Creative Commons BY-NC-SA.
  Fichiers utilisés : `src/assets/pictos/` (un pictogramme par mot, téléchargé par `outils/picto.mjs`).

- **Mondes des pirates, de la Gaule, de la Grèce antique et de la Chine** : images générées avec Gemini pour ce projet, d'après le style de `docs/style-images.md`. Premières versions, gardées comme modèles dans `docs/mondes/` (pas encore dans le jeu).
